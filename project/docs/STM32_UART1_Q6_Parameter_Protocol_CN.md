# MSPM0G3507 到 STM32 的 Q6 参数串口协议

## 用途与时序

底盘 MSPM0G3507 使用 UART2 向 STM32 单向发送数据。进入题目 2 至题目 6
时，都会先发送题号。题目 6 额外具有参数选择：操作员在 IPS200 上依次输入
带符号厘米值和带符号毫米值，确认后 MSPM0 再发送合成后的总偏移量。

题目 6 的完整时序如下：

```text
菜单选中 Q6，按 K3
  -> MSPM0 连发三次“进入题目 6”帧
  -> IPS200 选择 cm：K1 +1，K2 -1，范围 -15 至 +15
  -> K3 确认 cm
  -> IPS200 选择 mm：K1 +1，K2 -1，范围 -9 至 +9
  -> K3 确认 mm
  -> total_mm = cm * 10 + mm
  -> MSPM0 连发三次“Q6 参数”帧
  -> MSPM0 启动原有 Q6 循迹、计时和缓停程序
```

参数选择期间底盘电机保持停止，Q6 的循迹和计时尚未启动。选择页面按 K4
取消并返回主菜单；取消不会发送 Q6 参数帧。

## 接线与串口参数

| MSPM0G3507 | STM32 | 说明 |
| --- | --- | --- |
| UART2_TX_B15 | USARTx_RX | 单向数据线 |
| UART2_RX_B16 | USARTx_TX | 可选回传线，当前不需要连接 |
| GND | GND | 必须共地 |

两端都必须是 3.3 V TTL 电平，不能将 5 V TTL 直接接入任一 MCU 引脚。

```text
波特率：115200
数据位：8
校验位：无
停止位：1
流控：无
格式：115200 8N1
```

STM32 的 TX 当前不需要连接。除非电源方案明确要求，否则不要通过 UART
线连接两块板的 VCC。

## 通用规则

- 所有帧都以 `A5 5A` 开头，协议版本为 `01`。
- CRC 采用 CRC-8/ATM：多项式 `0x07`，初值 `0x00`，不反射，最终异或值
  `0x00`。
- 每一帧连续发送三次。STM32 必须把重复的合法帧视为同一个最新值，不能因
  三次重复而重复执行一次性动作。
- STM32 不需要回传确认帧；MSPM0 发送完成后继续自己的流程。

## 帧 1：进入题目

进入任意题目时发送，长度固定为 6 字节。

| 字节序号 | 字段 | 值 |
| --- | --- | --- |
| 0 | 帧头 0 | `A5` |
| 1 | 帧头 1 | `5A` |
| 2 | 协议版本 | `01` |
| 3 | 消息类型 | `01`，表示进入题目 |
| 4 | 题号 | `02` 至 `06` |
| 5 | CRC | 对字节 0 至 4 计算 CRC-8/ATM |

题目 6 的进入帧为：

```text
A5 5A 01 01 06 12
```

MSPM0 在显示 Q6 参数选择界面前就会发送该帧，所以 STM32 收到它后可以提前
知道当前即将进入题目 6。

## 帧 2：Q6 参数

仅在题目 6 的两个参数都按 K3 确认后发送，长度固定为 8 字节。

| 字节序号 | 字段 | 值 |
| --- | --- | --- |
| 0 | 帧头 0 | `A5` |
| 1 | 帧头 1 | `5A` |
| 2 | 协议版本 | `01` |
| 3 | 消息类型 | `02`，表示 Q6 有符号距离参数 |
| 4 | 题号 | 固定为 `06` |
| 5 | 距离高字节 | `distance_mm` 的位 15 至位 8 |
| 6 | 距离低字节 | `distance_mm` 的位 7 至位 0 |
| 7 | CRC | 对字节 0 至 6 计算 CRC-8/ATM |

MSPM0 的计算式为：

```text
distance_mm = centimeters * 10 + millimetres
```

厘米输入范围为 `-15…+15 cm`，毫米输入范围为 `-9…+9 mm`，所以 STM32 接受
的最终有效范围为 `-159…+159 mm`。距离字段使用 **16 位有符号整数**，单位为
毫米，采用 **大端序二进制补码**，不是 ASCII 文本。

例如：

| 输入 cm | 输入 mm | 合成值 | 完整帧 |
| --- | --- | --- | --- |
| -15 | -9 | -159 mm | `A5 5A 01 02 06 FF 61 B0` |
| 0 | 0 | 0 mm | `A5 5A 01 02 06 00 00 47` |
| 0 | 1 | 1 mm | `A5 5A 01 02 06 00 01 40` |
| 15 | 9 | 159 mm | `A5 5A 01 02 06 00 9F 93` |

## STM32 接收与解码要求

建议使用 UART 接收中断、DMA 循环缓冲区或 DMA Receive-to-Idle；不要在中断
中执行电机控制、延时、显示刷新或 `printf`。接收端必须把 UART 视为连续字节
流，而不是假定一次回调恰好得到一整帧。

建议解析状态机：

```text
等待 A5 -> 等待 5A -> 校验版本 -> 读取消息类型
  -> type=01：再收题号、CRC，共 6 字节
  -> type=02：再收题号、高字节、低字节、CRC，共 8 字节
  -> 校验 CRC、题号和参数范围 -> 发布结果
```

对于合法的 `type=0x02` 帧，应同时确认 `question == 6`。距离还原示例：

```c
uint16_t raw_distance = ((uint16_t)distance_hi << 8U) | distance_lo;
int16_t question6_distance_mm = (int16_t)raw_distance;

if (question6_distance_mm < -159 || question6_distance_mm > 159)
{
    /* 该帧无效，丢弃 */
}
```

帧头、版本、消息类型、题号、参数范围或 CRC 任一项不合法时，丢弃当前部分帧并
重新寻找 `A5`。若出错字节本身正好是 `A5`，可以把它当作下一帧的第一个帧头。
